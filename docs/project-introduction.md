# 카메라와 AI를 활용한 홍대거리 교통신호 최적화

> **한 줄 소개**  
> 도로 카메라로 차량과 보행자 흐름을 파악하고, 여러 교차로가 정보를 공유하며 신호를 조절하는 AI 기반 교통 최적화 시스템입니다.

## 기존 프로젝트 발표 영상

[Computer Vision-Based Smart Traffic Light and Traffic Flow Optimization System](https://youtu.be/AYuUVxm_5rw)

이 영상은 기계학습심화 강의에서 진행한 단일 교차로 프로젝트의 아이디어와 구현 결과를 설명합니다.

## 어떤 문제를 해결하려는 프로젝트인가요?

일반적인 교통신호는 정해진 주기를 반복하거나 제한된 센서 정보에 반응합니다. 하지만 홍대거리는 시간과 장소에 따라 차량과 보행자 흐름이 크게 달라집니다.

- 홍익대학교 학생과 교직원이 집중되는 등하교·출퇴근 시간
- 2호선 홍대입구역 9번 출구 주변의 학생과 방문객
- 공항철도와 경의중앙선을 이용하는 관광객
- 레드로드와 주변 상권에 집중되는 보행자
- 평일, 주말, 행사 시간에 따라 달라지는 교통 특성

따라서 차량만 빠르게 통과시키는 방식보다, **차량 정체와 보행자 대기시간을 함께 고려하는 신호 제어**가 필요합니다.

이 프로젝트는 카메라 영상에서 현재 교통 상황을 인식하고, 여러 교차로의 정보를 함께 이용해 차량 신호와 보행자 신호를 유동적으로 조절하는 것을 목표로 합니다.

## 기존에 구현한 내용

지난 기계학습심화 강의에서는 **Computer Vision-Based Smart Traffic Light and Traffic Flow Optimization System**을 주제로 약 3주간 프로젝트를 진행했습니다.

당시 프로젝트에서는:

- 홍익대학교 정문 앞 교차로 하나를 대상으로 삼고
- YOLO로 영상 속 차량을 인식하고
- SUMO와 `sumo-rl`로 교통 상황을 시뮬레이션하고
- 강화학습을 이용해 차량 신호를 조절하는 구조를 구현했습니다.

다만 짧은 강의 프로젝트였기 때문에 다음과 같은 한계가 있었습니다.

- 하나의 교차로만 다룸
- 차량 흐름을 중심으로 최적화함
- 주변 교차로와의 상호작용을 고려하지 않음
- 무작위로 생성한 교통 수요를 사용함
- 학습 모델과 기존 신호 방식의 비교·검증이 충분하지 않음

## 졸업프로젝트에서 확장할 내용

이번 프로젝트에서는 기존 단일 교차로 실험을 홍대거리의 다중 교차로 문제로 확장합니다.

```text
카메라 영상 또는 SUMO 시뮬레이션
                ↓
       차량·보행자 상태 생성
                ↓
   인접 교차로 사이의 교통 정보 공유
                ↓
 AI가 차량·보행자 신호의 동작을 결정
                ↓
 기존 신호 방식과 정량적으로 성능 비교
```

초기에는 홍익대학교 정문 앞 교차로와 홍대입구역사거리를 연결한 2개 교차로 MVP를 구현합니다. 이후 팀 규모와 일정에 따라 2호선 9번 출구, 공항철도 방향, 레드로드 일부까지 확장할 수 있습니다. 상수역 방향은 필수 범위가 아닌 추가 확장 후보입니다.

카메라를 바로 설치하기 어려운 현실을 고려해 시스템을 두 모듈로 분리합니다.

1. 영상에서 차량과 보행자를 인식하는 비전 모듈
2. 홍대거리 교통과 신호제어를 실험하는 SUMO 시뮬레이션 모듈

두 모듈은 같은 교통 데이터 구조를 사용합니다. 졸업프로젝트에서는 녹화 영상과 시뮬레이션으로 검증하고, 향후 실제 카메라가 준비되면 동일한 연결 구조를 활용할 수 있도록 설계합니다.

## 현재 진행 상황

현재까지 다음 작업을 완료했습니다.

- 기존 Colab 프로젝트를 Git 저장소로 이전
- 단일 교차로 SUMO 실험의 재현 환경 복구
- 고정 신호, 감응식 신호, 기존 강화학습 모델의 비교 환경 구축
- 여러 랜덤 시드를 동일한 조건에서 비교하는 평가 절차 구축
- 기존 코드와 결과 자산의 변경을 검출하는 검증 추가
- SUMO와 영상 인식 결과가 공통으로 사용할 `TrafficSnapshot` 구조 구현
- 하나의 물리적 교차로에 여러 신호 제어기가 있는 구조 지원
- 다중 교차로 연결 관계를 검증할 수 있는 `SUMOAdapter` 기반 구현
- 기존 단일 교차로 맵과 새로운 홍대거리 맵을 분리하는 방침 수립
- 신규 OSM 네트워크의 후보 범위와 주요 기준점 조사

기존 강화학습 모델이 모든 조건에서 가장 좋다고 결론 내린 상태는 아닙니다. 재검증 과정에서 일반적인 감응식 신호가 더 좋은 경우도 확인했습니다. 따라서 결과를 미리 정해두기보다, **어떤 교통 상황에서 AI 제어가 효과적인지 공정하게 검증하는 것**을 중요하게 생각합니다.

## 앞으로의 목표

1. 홍대거리 구간의 OSM 데이터를 기반으로 새로운 SUMO 네트워크 구축
2. 실제 도로의 차로, 회전 연결, 신호, 보도와 횡단보도 구조 검증
3. 홍익대학교 정문과 홍대입구역사거리의 2개 교차로 MVP 구현
4. 차량 및 보행자 수요 시나리오 설계
5. 등하교, 주말 관광객, 지하철 도착 직후와 같은 상황 구현
6. 차량 정체와 보행자 대기시간을 함께 고려하는 평가 기준 설계
7. 다중 교차로 신호제어 및 강화학습 적용
8. 고정 신호·감응식 신호·AI 신호의 정량적 성능 비교
9. YOLO 기반 차량·보행자 인식 모듈 연결
10. 결과를 쉽게 확인할 수 있는 시각화 및 데모 제작

## 팀 프로젝트로 확장하기 좋은 이유

프로젝트가 독립적인 모듈로 나뉘어 있어 팀원의 관심 분야와 기존 주제를 반영하기 좋습니다.

| 분야 | 가능한 작업 |
| --- | --- |
| 컴퓨터 비전 | YOLO 기반 차량·보행자 탐지, 추적, 카운팅 |
| 교통 시뮬레이션 | OSM/SUMO 네트워크, 차량·보행자 수요 시나리오 구축 |
| 강화학습 | 상태·행동·보상 설계, 다중 교차로 신호 최적화 |
| 데이터 분석 | 시간대별 교통 특성 모델링, 실험 결과 분석 |
| 서버·통신 | 인식 모듈과 제어 모듈 연결, 교차로 정보 공유 구조 |
| 시각화 | 실시간 상태 및 실험 결과 대시보드, 시연 화면 |
| 평가 | 기존 신호 방식과 AI 방식의 통계적 비교 |

팀이 구성되면 각 구성원이 기존에 준비했던 주제를 검토해 다음처럼 다시 설계할 수 있습니다.

- 프로젝트의 공통 핵심 목표로 통합할 기능
- 독립 모듈로 결합할 수 있는 기능
- 일정과 인원에 맞춰 축소하거나 제외할 기능

따라서 기존 주제가 영상 인식, 데이터 분석, 강화학습, 서버, 웹 또는 시각화와 관련되어 있다면 아이디어를 일부 유지하면서 이 프로젝트와 통합할 수 있습니다.

## 최종 목표

단순히 강화학습 모델을 한 번 실행하는 데 그치지 않고, **홍대의 차량·보행자 특성을 반영하면서 실제 카메라 시스템으로도 확장할 수 있는 검증 가능한 교통신호 최적화 프로토타입**을 만드는 것이 최종 목표입니다.

프로젝트의 세부 범위와 역할은 팀 구성원의 인원, 관심 분야, 기존 계획을 함께 검토한 뒤 조정할 예정입니다.
